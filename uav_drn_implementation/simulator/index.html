Model. PLoS(θ) = 1 / (1 + a·e−b(θ−a)); mean path loss = FSPL + PLoS·ηLoS + (1−PLoS)·ηNLoS. Link budget: 3 dBi UAV antenna, 3 dB losses, maximum path loss 100 dB at 20 dBm (scaled with transmit power), 7 dB noise figure, service threshold SINR ≥ 0 dB. Users share their UAV's bandwidth equally; rate = (B / n) · log₂(1 + SINR).

Browser version of the team's Python implementation (uav_drn) for the Wireless & Mobile Communication case study, SRM Institute of Science and Technology. The Hybrid strategy here uses a lighter swarm than the Python code, so its numbers can differ slightly.
